Política de privacidad de SOP-IA

Última actualización: 13 de octubre de 2026.

SOP-IA es una herramienta de asistencia personal administrada por el titular de la cuenta. Esta política describe el tratamiento de datos al conectar una cuenta Google.

Datos y permisos

La autorización OAuth identifica la cuenta mediante su dirección de correo electrónico e identificador. Los permisos de Google Calendar permiten consultar calendarios y eventos y gestionar los cambios solicitados. Los permisos de Google Drive permiten consultar y gestionar archivos, incluidos documentos y copias de seguridad privadas. Solo se realizan operaciones necesarias para las funciones que el titular solicita o autoriza.

Uso de los datos

Los datos se utilizan para organizar la agenda, asistir con tareas y archivos, y crear o recuperar copias de seguridad. No se venden, no se usan para publicidad, perfiles comerciales ni entrenamiento de modelos de inteligencia artificial de propósito general.

Almacenamiento y protección

Las credenciales OAuth y los datos necesarios para prestar estas funciones se conservan en entornos privados con acceso restringido. Las copias de seguridad enviadas a Google Drive se cifran antes de su almacenamiento. La retención se limita a lo necesario para el servicio, la continuidad y la recuperación; el titular puede solicitar la eliminación de los datos y copias conservados.

Transferencias y acceso

Google procesa los datos necesarios para sus servicios Calendar y Drive. Cuando el titular solicita asistencia con contenido, los datos estrictamente necesarios pueden ser procesados por proveedores de asistencia y procesamiento de IA para cumplir esa solicitud. No se comparten públicamente. El acceso humano se limita al titular o a personas expresamente autorizadas, y a los supuestos necesarios de seguridad o cumplimiento legal. Las transferencias se limitan a prestar las funciones autorizadas, proteger la seguridad o cumplir obligaciones legales.

Control y eliminación

Podés revocar el acceso en cualquier momento desde las conexiones de tu cuenta Google. Revocar el acceso impide nuevas operaciones, pero no elimina automáticamente archivos, copias o datos ya conservados. Podés eliminar los archivos de Drive y solicitar la eliminación de los datos privados conservados por SOP-IA.

Compromiso con las políticas de Google

El uso y la transferencia de información recibida de las API de Google se ajustarán a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Este sitio y contacto

Este sitio informativo no recopila credenciales ni incorpora analítica, formularios o rastreadores propios. GitHub Pages puede registrar datos técnicos de las visitas conforme a la política de privacidad de GitHub.

Para consultas generales, contactá al administrador. No publiques datos personales, archivos privados, credenciales ni solicitudes de eliminación con información sensible en ese canal público; usá el canal privado habitual con el administrador.
